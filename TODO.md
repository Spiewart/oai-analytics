## Features

### Lo 2022 replication (`analyses/lo2022_walking`)

- **Confirm how "yes" walkers with blank amount items were coded** — <!-- skip --> Ask the original authors whether respondents who answered yes to `V10WLKAR4` but left years, months/year and times/month all blank were coded as non-walkers. There are 27 such participants. Coding them as non-walkers reproduces the published 887 walkers exactly (`oai run lo2022_walking --variant walker_requires_amount`: 111 rows replicated vs 77). If yes: set the `exposure.yes_without_amount_as` default to `"non-walker"`, change its status to `confirmed`, cite the authors, and run `oai assumptions lo2022_walking --write`. If no: keep it as a documented sensitivity variant.
  [analyses/lo2022_walking/assumptions.toml](analyses/lo2022_walking/assumptions.toml)

- **Confirm whether a knee replaced at baseline counted toward radiographic OA eligibility** — <!-- skip --> Ask in the same message. Counting participants whose OA knee was replaced at baseline reproduces the published 2,356 at that flow step exactly (`--variant roa_counts_replaced_knees`). The paper's text says "native knee", and the variant slightly lowers the overall grade. Update `cohort.roa_counts_replaced_knees` with the answer.
  [analyses/lo2022_walking/assumptions.toml](analyses/lo2022_walking/assumptions.toml)

### Enclave hardening (before the genetics project)

- **`run.sh` preflight**: fail early unless `python3` is ≥ 3.11 and the bundle is extracted inside `$OAI_GENO_DIR`. Add `--disable-pip-version-check` for offline installs.
  [src/oai/export/templates/run.sh](src/oai/export/templates/run.sh)
- **`oai export --out` guard**: refuse output directories inside the repository; the tarball contains the ID-bearing frame.
  [src/oai/export/bundle.py](src/oai/export/bundle.py)
- **Atomic cache writes**: give the Parquet temp file a unique name and write the sidecar JSON atomically, so concurrent builds and crashes can't leave a corrupt cache.
  [src/oai/loader.py](src/oai/loader.py)
- **Egress: symlinked subdirectories** are skipped by `rglob`; they should fail closed.
  [src/oai/export/egress.py](src/oai/export/egress.py)
- **CI leak scan per commit + pre-push hook**: scan every commit in a push/PR range, not just the tip.
  [.github/workflows/ci.yml](.github/workflows/ci.yml)
- **Python↔R interop tests in CI**: the Python job has no R, so `tests/test_r_interop.py` and `tests/test_lo2022_models.py` always skip there.
- **Run steps outside the repo**: steps currently run with the analysis folder as the working directory, so relative writes land in the repo.
  [src/oai/runner.py](src/oai/runner.py)
- **Resolve `[inputs]` at run time**: fail fast when a declared input table or visit is missing from the catalog (spec §7.4).
  [src/oai/runner.py](src/oai/runner.py)
- **Codebook key types**: label keys are strings while loaded values are Int64.
- **Case-variant paths**: on case-insensitive filesystems a differently-cased work dir can bypass the inside-repo check.
  [src/oai/config.py](src/oai/config.py)
